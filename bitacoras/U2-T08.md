## Desviaciones y huecos de especificación
1. **CA-6 grep devuelve 1, no 0, también en `origin/main`**: el único archivo es `services/go-run-controller/runner/runner_test.go` (líneas 184/198), una prueba *negativa* que usa `OPENAI_API_KEY` como nombre de variable prohibida. No hay credenciales de LLM; no se tocó (falso positivo preexistente de la expresión).
2. **`run.confirmed` no lleva workflow** y `Run.Workflow` nunca se rellena; no se pueden tocar `contracts/**`. Se añadió `U3_DEFAULT_WORKFLOW` como respaldo (sin ninguno el plan falla cerrado).
3. `FlowSource.Flows(runID)` no recibe superficie ni workflow: el adaptador los obtiene por inyección (`WarmClient.Surface`, almacén) sin cambiar la interfaz.
4. CA-4: el patrón `^\s*(kubectl …)` exige 0, así que las órdenes se escriben con prompt `$ ` tras el marcador; el revisor debe verificarlo leyendo.
5. `RUN_FLOW_SOURCE=fake` queda guardado como el resto de fakes; en modo real cablea `stubs.FakeFlowSource`.
6. El contrato U2↔U3 asume la API real del planner (`POST /v1/plan`, cuerpo `{surface, workflow}`, sin auth) leída de `agents/agent-planner/.../server.py` (solo lectura).
