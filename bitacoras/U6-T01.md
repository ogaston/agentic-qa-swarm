### Rojo del proxy (defecto encontrado en verificación real)
Arranqué Vite de verdad con destinos de eco y `curl`:
```
$ curl http://localhost:5994/api/authz   (versión inicial de toViteProxy, claves string)
/api/authz -> 9101 /authz      # 9101 = identidad: INCORRECTO, debía ir a ui-api
```
Causa: Vite compara las claves string por prefijo literal (`startsWith`), no por segmento.
Prueba nueva que lo reproduce:
```
$ npx vitest run src/proxy
× las claves de toViteProxy casan por segmento, igual que resolveProxy
AssertionError: expected 'http://identity.local:8081' to be 'http://ui-api.local:8083'
```
