Manifiesto declarativo generado (GitOps / Flux)

Este manifiesto representa la configuración de la aplicación gestionada por el control plane de Agentic QA Swarm. 

apiVersion: aqs.javeriana.edu.co/v1alpha1
kind: TargetApplication
metadata:
  name: payments-service
  namespace: aqs-system
spec:
  repository:
    url: https://github.com/omarjayg/payments-service
    branch: main
    events:
      - commit
      - pull_request
      - tag
  artifact:
    imagePattern: ghcr.io/omarjayg/payments-service:{{sha}}
    port: 8080
    healthProbe: /healthz
  environment:
    namespace: aqs-test
    database: postgres
    cache: redis
    resetProtocol: truncate-and-flush
    baselineSeed: scripts/seed/baseline-products.sql
  governance:
    confirmationRequired: true
    maxTimeoutMinutes: 15
    networkIsolation: deny-staging-prod
