🎯 1. What Is This Project About? (The 30-Second Essence) Black-box transactional logic QA
A platform that intercepts GitHub events (commit, PR, tag), seeks human confirmation, deploys the software into an isolated Warm Sandbox (reusable app + DB + Redis inside platform cluster), infers external endpoints, generates & rehearses deterministic tests, runs them, and executes a 100% verified reset before delivering a business-logic post-mortem.

No Autonomous Execution: Every run requires explicit human approval via the inbox. Zero autonomous cluster creation.
