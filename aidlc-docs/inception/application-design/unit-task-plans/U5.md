> Historias: US-M10. Reglas: cada criterio se verifica con un comando (AUTONOMIA-02); ningún paso aplica cambios a clúster/nube sin aprobación humana registrada — los manifiestos son artefactos revisables en PR (AUTONOMIA-01).

| # | Tarea | Criterio de aceptación (comando) |
|---|---|---|
| U5-T1 | Esqueleto monorepo (`services/`, `agents/`, `contracts/`, `deploy/flux/<base\|dev\|prod>`, `.github/workflows/`) + README de layout | `ls` muestra el árbol; `git status` limpio tras commit inicial |

| U5-T7 | Observabilidad base: logging estructurado (timestamp/request-id/nivel/mensaje), métricas, dashboard y retención ≥90d (manifiestos + docs) | `promtool check rules` (o equivalente) pasa; retención configurada visible en el manifiesto (sin apply autónomo) |
| U5-T8 | Backups Backup&Restore (cron + retención + cifrado) + runbook de restore + propuesta de change mgmt ligero e IR/COE (AR2/AR7) | `kubeconform` pasa el CronJob; runbook + procesos documentados y enlazados en el repo |
