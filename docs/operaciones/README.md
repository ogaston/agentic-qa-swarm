# Operaciones de la plataforma

Procesos operativos de Agentic QA Swarm (U5).

- [Runbook de restore](runbook-restore.md): backup de evidencias, RTO/RPO, validacion, failover y failback.
- [Gestion de cambios](gestion-de-cambios.md): registro de cambio, aprobacion y nota de rollback.
- [Respuesta a incidentes](respuesta-a-incidentes.md): alerta, runbook, post-mortem y COE con plantilla.
- [Bootstrap de Flux](bootstrap-flux.md): arranque unico por clúster y verificacion con `flux get kustomizations`.
- [Secrets (SOPS + age)](secrets.md): generar la clave, crear `sops-age`, generar/cifrar, rotar y respuesta a fuga.
